# M-PESA Analyzer App

This Android application helps you analyze and track your M-PESA transactions efficiently. It processes your M-PESA SMS messages to categorize and visualize spending and receiving habits.

## Features
- Interactive graphs for financial insights
- Detailed transaction history and summaries
- Privacy-first local processing
- Biometric lock
